# TUNE VVO — instalador Universal para macOS (Português)

*[Read in English ↓](#tune-vvo--macos-universal-installer-english)*

`TuneVVO-1.0.2-macOS-Universal.pkg` — para **todo Mac com macOS 11 Big Sur ou posterior**:
todos os Macs Apple Silicon (M1, M2, M3, M4 e posteriores) e Macs Intel.

Instala VST3 e Audio Unit (AU). É o único instalador para Mac: serve para todos os Macs, do macOS 11 Big Sur ao macOS 26 Tahoe.
