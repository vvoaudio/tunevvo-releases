# TUNE VVO — instalador Universal para macOS (Português)

*[Read in English ↓](#tune-vvo--macos-universal-installer-english)*

`TuneVVO-1.0.1-macOS-Universal.pkg` — para **todo Mac com macOS 11 Big Sur ou posterior**:
todos os Macs Apple Silicon (M1, M2, M3, M4 e posteriores) e Macs Intel.

Instala VST3 e Audio Unit (AU). É o mesmo plugin e o mesmo som do instalador para Tahoe; use este se o seu Mac tiver algo anterior ao macOS 26 Tahoe.

Os passos de instalação (inclusive o **Abrir Mesmo Assim**, feito uma única vez) estão no [README principal](../README.md#instalar-no-mac).

Testado: instalado sobre uma cópia antiga existente (inclusive do nome anterior, VvoTune) e validado (pluginval no nível de rigor 10 + 56 verificações de som) no macOS 15 Sequoia (Apple Silicon). Compilado para o mínimo de macOS 11.0.
